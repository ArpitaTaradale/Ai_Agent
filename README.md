 AI Study Planner
 Project Description

AI Study Planner is a Python-based application that helps students create a personalized study schedule based on their subjects, number of chapters, available study hours, and exam date.

The project was developed using AI-assisted coding with GitHub Copilot.

   Features
 Takes the student's name
 Accepts multiple subjects and chapter counts
 Takes available study hours per day
 Calculates the number of days remaining before the exam
 Calculates total chapters
 Recommends chapters to study per day
 Generates a daily study plan
 Provides study suggestions based on available study hours
 Validates the exam date
 Technologies Used
Python
datetime
timedelta
GitHub Copilot
 How to Run
Install Python on your system.
Clone or download this repository.
Open the project folder in VS Code or another Python IDE.
Run the following command:
python study_planner.py
Enter the required details when prompted.
